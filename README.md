# File Protection Utility

## Description
This project protects text by converting it into an encoded format and restores it back when required.

It demonstrates:
- Data protection
- Encoding and decoding
- Controlled access using Python

## Features
- Protect text
- Restore protected text
- Simple menu-based program

## Technologies Used
- Python
- Base64 module

## Example

Input:
hello

Protected:
aGVsbG8=

Restored:
hello
